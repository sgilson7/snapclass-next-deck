# SnapClass Next for Developers

A slide deck for the SnapClass dev team: SnapClass's current architecture and how it grew, microservices, the SnapClass Next rework (a protected core of services plus mods), writing a mod, testing, one-touch releases, smoke before prod, and working in the repository.

Open it at https://sgilson7.github.io/snapclass-next-deck/. Arrow keys move between slides; each animation has a Play button and a text list of its steps.

`index.html` is generated; it is not edited here. Counts and the SnapClass Next code beside each animated step are checked against the code when the deck is built. Code from today's SnapClass is left out of this public copy.

Sam Gilson, Game2Learn lab, NC State. Deck structure after [WebSlides](https://github.com/webslides/WebSlides) (MIT).
